# Brand

- `sign-reference.webp`: photo of the entrance sign. It's the reference for the
  website's lettering (CASA GRANDE / APARTMENTS) and the CG laurel monogram.
- The monogram is drawn in code (`src/components/Monogram.astro`, `public/favicon.svg`).
  `make-monogram.py` regenerates its shapes from the EB Garamond font
  (requires Python with `fonttools` and `brotli`).
